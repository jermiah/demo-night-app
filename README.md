## ⚙️ Quick Start

```bash
# 1. Install dependencies
yarn install

# 2. Start database (Docker)
./start-database.sh

# 3. Run migrations
yarn db:migrate

# 4. Start dev server
yarn dev
```

For detailed instructions, please see the [Development Guide](./DEVELOPMENT.md).
